# DR. ARMASY MUANA NZAMBI — Loja Digital v2
1. Extraia o ZIP e abra `index.html` no Chrome/Edge.
2. No computador, pressione `Ctrl + Shift + A` para abrir a área do vendedor. No telefone, toque cinco vezes no copyright do rodapé.
3. Preencha os dados do produto, selecione o ficheiro digital (PDF/EPUB, MP3, MP4 etc.) e clique em Guardar produto.
4. Na área do vendedor pode listar produtos, descarregar ficheiros guardados e eliminar produtos.

IMPORTANTE: produtos, ficheiros e encomendas ficam apenas no navegador/dispositivo local. Esta versão serve para testar; ainda não entrega ficheiros a compradores pela Internet, não sincroniza com outros dispositivos, não tem área de administrador protegida e não processa pagamentos automaticamente. Para vender online, precisamos ligar Supabase e implementar armazenamento privado, autenticação e entrega segura após confirmação de pagamento.
