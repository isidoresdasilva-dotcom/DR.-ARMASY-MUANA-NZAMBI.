# DR. ARMASY MUANA NZAMBI — Loja Digital v1

## Abrir no computador
1. Extraia o ficheiro ZIP.
2. Abra a pasta extraída.
3. Dê duplo clique em `index.html` (Chrome, Edge ou Firefox).

## Adicionar os seus produtos
- No computador, pressione `Ctrl + Shift + A` para abrir a área do vendedor.
- No telefone, toque cinco vezes na linha de copyright no rodapé.
- Preencha nome, categoria, preço, descrição e opcionalmente o URL da imagem.
- Os produtos e encomendas ficam guardados no armazenamento local desse navegador.

## Importante
Esta é uma primeira versão demonstrativa que funciona localmente. Ainda não é uma loja online pronta para receber encomendas pela Internet:
- Não sincroniza dados entre computador e telefone.
- A área do vendedor não está protegida por palavra-passe.
- Não inclui login Google nem ligação ao Supabase.
- Não processa pagamentos automaticamente; encomendas são registadas localmente e o pagamento deve ser confirmado manualmente.
- Não disponibilize publicamente links de produtos pagos antes de confirmar o pagamento.
Para vender a clientes reais pela Internet, o passo seguinte é ligar Supabase, proteger a área do vendedor e configurar um processo seguro de confirmação de pagamento e entrega.
